# Invisible Maze Runner 

## Introduction

Invisible Maze Runner is a simple maze game developed using C programming. The idea behind the game is to find the exit of a maze that is not fully visible to the player.

When the game starts, most of the maze is hidden. As the player moves around, nearby areas become visible. The player has to explore different paths, avoid walls and find the exit.

## What Does the Game Include?

- A maze that is initially hidden.
- Player movement using W, A, S and D keys.
- Nearby maze cells become visible as the player moves.
- Walls that block the player's movement.
- An exit that the player needs to find.
- A move counter to keep track of movements.
- A menu and game interface.

## How to Play

Playing the game is simple:

1. Start the game.
2. Use W, A, S and D to move around.
3. Explore the hidden areas of the maze.
4. Find the correct path while avoiding walls.
5. Reach the exit to finish the game.

### Controls

| Key | Movement |
|---|---|
| W | Up |
| A | Left |
| S | Down |
| D | Right |

## Project Files

The project is divided into different files so that each part of the game can be developed and managed separately.

- `main.c` – Runs the main game.
- `maze.c` and `maze.h` – Handle the maze layout and visibility.
- `player.c` and `player.h` – Handle player movement.
- `menu.c` and `menu.h` – Handle the game menu.
- `README.md` – Contains information about the project.
